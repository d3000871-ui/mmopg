## 🎮 Kengaytirilgan O'yin Imkoniyatlari:

1. **👑 Eng Oliy Unvon: "ALIY SARKARDA"**:

   - Eng oliy, yuksak martaba — **"ALIY SARKARDA"** (Oliy Bosh Qo'mondon)!

2. **🔥 Personaj Darajasi: 1000 (Hardcore Progression)**:
   - 1-dan 100-darajagacha qulay va maroqli rivojlanish.
   - **100-darajadan yuqorisi (101 - 1000)** esa keskin qiyinlashadi: haqiqiy pahlavonlar jangi, minglab maxluqlarni yengish va afsonaviy zindonlar orqali ko'tarilish!

   - Zarbalar dushmanning po'lat zirhini teshib, yerga haqiqiy qon sachraydi va qon ko'lmaklari hosil bo'ladi.

     - 🔮 **Alvon Tosh:** +31 dan +70 gacha
